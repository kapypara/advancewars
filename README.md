# Advance Wars Recompiled (Zig)

A pure-Zig (`0.17.1`) static recompilation of **Advance Wars** (GBA, USA Rev 1) built from your own ROM. The custom ARM/Thumb static recompiler (`src/recomp/`), GBA hardware core (`src/gba/`), runtime (`src/runtime.zig`), and display/audio/touch frontends (`src/platform/`) are written in Zig; generated ROM code lands in `gen/` on your machine and no emulator runs underneath.

## Status

- **Pure-Zig recompiler & runtime:** `7,577` functions (`64,740` basic blocks) statically recompiled into parallel Zig shards (`gen/`), with `165/165` lockstep interpreter conformance (`zig build conformance`).
- **Graphics:** Per-scanline Zig PPU (`src/gba/ppu.zig`) supporting Modes 0/3/4, regular & affine BGs/sprites, windows, and color effects; pixel-exact parity with the C baseline across `replays/title.txt`, `replays/field_training.txt`, and `replays/field_training_win.txt`.
- **Audio:** Pure-Zig GBA DirectSound A/B + `m4a` mixer (`src/gba/audio.zig`) with 4-tap Catmull-Rom resampling, Butterworth low-pass filter, DC blocker, and dynamic queue-rate control.
- **Saves:** 64 KB Flash (`FLASH_V121`, `.sav`) and EEPROM (`src/gba/flash.zig`) load/save round-trips verified.
- **Controls & UI:** Native SDL2 window (`src/platform/sdl2.zig`) with keyboard, direct map/dialog touch & mouse navigation plus toggleable corner HUD (`src/platform/touch.zig`).

## Quick Start

You need your own **Advance Wars (USA) (Rev 1)** ROM (`game/aw.gba`, SHA-1 `15053499d5b3f49128a941d7f2d84876f5424d0c`). Nothing here downloads or bundles game data.

### Podman Compose (reproducible dev environment)

1. Place your ROM at `game/aw.gba`.
2. Translate the ROM into pure-Zig shards under `gen/`:
   ```bash
   podman compose run --rm dev zig build translate
   ```
3. Build and run unit tests / conformance / smoke checks:
   ```bash
   podman compose run --rm dev zig build test --summary all
   podman compose run --rm dev zig build -Doptimize=ReleaseFast
   podman compose run --rm dev zig build conformance
   podman compose run --rm dev zig build smoke
   ```

### Native Linux host

Requires Zig `0.17.1` and SDL2 (`libsdl2-dev` / `sdl2`, optional with `-Dheadless=true`):

```bash
zig build translate
zig build -Doptimize=ReleaseFast
./zig-out/bin/awre game/aw.gba
```

## Controls & Usage

- **GBA keys:** Arrow keys = D-Pad, `Z` = A, `X` = B, `Enter` = Start, `Backspace` = Select, `A`/`S` = L/R
- **Window / UX hotkeys:** `F11` = fullscreen, `F2` = toggle touch HUD (`L`/`ST`/`R`/`B`/`A`), `F3` or `M` = toggle mute
- **Mouse / touch:** Click/tap map tiles to move the cursor and confirm; drag to pan; click corner HUD pills (`F2`)

Headless runs, screenshots, MP4 capture, and per-frame state dumps:

```bash
./zig-out/bin/awre game/aw.gba --headless --frames 8000 --input replays/field_training.txt --screenshot scratch/ft.bmp
./zig-out/bin/awre game/aw.gba --record scratch/intro.mp4 --frames 3600
./zig-out/bin/awre game/aw.gba --dump-dir scratch/edge_dump
```

See [docs/DEBUG_DUMPING.md](docs/DEBUG_DUMPING.md) for `--dump-dir`, `--dump-at`, and `GBA_WATCH` diagnostics, [docs/ZIG_PORT_PLAN.md](docs/ZIG_PORT_PLAN.md) for the port roadmap, and [ROADMAP.md](ROADMAP.md) for the original upstream reference.

## Project Layout

- `src/recomp/` — Pure-Zig GBA static recompiler (`gbarecomp`)
- `src/gba/` — Freestanding GBA hardware core (PPU, audio mixer, Flash/EEPROM, timers, DMA, BIOS HLE, ARM/Thumb interpreter)
- `src/platform/` — Display ABI, headless runner, touch controller, and SDL2 backend
- `src/validate/` — Host-only lockstep conformance harness (`GBA_VALIDATE`)
- `src/main.zig`, `src/root.zig`, `src/runtime.zig`, `src/shard.zig` — Entry point, module root, GBA bus/IRQ runtime, and shared shard ABI
- `gen/` — Gitignored ROM-translated Zig shards (generated by `zig build translate`)
- `replays/` — Deterministic headless input scripts (`title.txt`, `field_training.txt`, `field_training_win.txt`, `field_training_m2.txt`)
- `scripts/` — Self-contained `conformance.sh` and `smoke.sh` runners
- `docs/` — Architecture notes, debugging guide, screenshots, and Zig port plan
